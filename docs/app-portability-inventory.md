## How to read this table

- **Has ambient dependencies** → the app is bound to `os` today (§7.2's debt list). To make it portable,
  first converge fs / network / process into injected capability objects, then have each of the three
  runtime tiers implement them (§7.5-3).
- **Undeclared · not yet measured** → the code does not touch system APIs, but **that is not enough**
  to prove it can run in browser/sandbox: a package it depends on may touch them itself, or use
  semantics that exist only on OS. Only an actual run counts (P3's acceptance).
- **abi column** → only present for those with `effect.bundle.json`; a missing `runtimes` means
  `["os"]` (conservative default).
- In-memory state that cannot be rebuilt after a kernel switch needs manual cross-checking and is
  not in this table — see `docs/architecture-rework.md` §6.3.
